# Sparse Finch Benchmark

This fork is meant show the comparison between original version of TensorTools
for MCP-ALS with dense NumPy implemention and sparisified Array API compatible
implementation compiled with Finch.jl project.

You can run it with full config grid with:

```sh
. run_benchmark.sh
```

Feel free to customize it to your liking by editing `run_benchmark.sh`.

Hardware used in the original setup:

```
Linux x86_64
AMD Ryzen Threadripper 3970X 32-Core Processor
```
